📊 Algorithm Explanation

Random Forest works by:

Creating multiple decision trees.

Training each tree on a random subset of data.

Aggregating results:

Classification → Majority Voting

Regression → Average Prediction

This reduces:

Overfitting

Variance

Improves accuracy
